# pruzicka/tap

Homebrew formulae.

```sh
brew install pruzicka/tap/wallpaper-picker
```

| Formula | |
|---|---|
| [wallpaper-picker](https://github.com/pruzicka/wallpaper-picker) | Pick macOS wallpapers from a fanned deck of colour-chip cards |

Formulae here build from source, so the apps they install aren't blocked by
Gatekeeper and need no notarization.
